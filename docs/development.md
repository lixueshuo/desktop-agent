# 开发记录

## 2026-10-29：初始原型

在 AI 辅助下实现后端循环、四个工具及 Tkinter 桌面原型。8 项后端测试通过，并验证 DeepSeek 实际调用。原型不等于最终作业，正式界面、MCP、打包与交付材料尚待实现。

## 2026-10-30：文件工具报错改进

本次只改进 read/edit 三种失败提示：文件不存在、误传目录、非 UTF-8 文件。提示包含相对路径及下一步建议，不返回整段系统异常。编码错误时不尝试覆盖文件。

新增三个回归测试，分别验证上述情况，检查缺失文件不会被创建、目录仍是目录、无法解码的文件字节保持不变。保留原有 CRLF 精确修改测试。

验证命令：`python -m unittest discover -s tests -v`。本次无需调用模型，不消耗 API 额度。

## 2026-10-31：正式桌面界面第一阶段

新增 pywebview 窗口及 ui/index.html 三栏页面，接通练习项目文件列表与带行号的只读预览。界面使用 textContent 显示文件内容，避免将代码作为 HTML 执行；文件读取仍通过原有路径限制。对话按钮明确禁用，等待后续接入，旧 Tkinter 原型继续保留。

运行：先执行 python -m pip install --target .desktop-deps -r requirements-desktop.txt，再执行 python desktop.py。依赖版本锁定为 pywebview 6.2.1。Windows 需要 WebView2 运行时。

文件桥接检查通过，依赖安装完成。实际窗口视觉检查尚待完成。本次未调用模型。

## 2026-11-01：正式窗口接入任务和中断

新增后台任务线程、事件轮询和中断桥接；正式页面开放发送任务，显示工具调用、修改 diff、失败与最终回答。运行中拒绝重复任务；结束事件恢复按钮。中断沿用后端取消标记，等待中的 HTTP 最迟60秒超时，不声称立即结束网络请求。

新增桥接测试：取消与重复任务、模型错误后的结束事件。窗口视觉及真实模型交互尚待实际验收。本次测试使用模拟模型，不消耗 API 额度。

## 2026-11-03：自动保存运行事件

新增 .runs/*.jsonl 自动记录，包含任务开始、逐步工具事件、结果及模型异常，逐条刷新到磁盘。记录有 UTC 时间与唯一文件名，真实模型标记 live，模拟模型标记 test-double。已配置的模型 Key 会脱敏；工具输出仍可能包含项目私密信息，因此整个 .runs 目录忽略上传，分享前需人工检查。

记录失败会发出 trace_warning 并继续任务。正式窗口会显示该提示。新增两项测试，验证文件名唯一、Key 脱敏、模拟异常的标记与持久化；全部15项测试通过。本次未调用付费模型，不是完整失败恢复演示。MCP 和真实恢复 trace 仍待完成。11月2日无开发记录，不补日期。

PyInstaller 6.22.3 已构建首个 Windows 程序，冻结运行时配置与日志放用户目录 DesktopAgent。仍需窗口实际验收、配置入口、可安装发布包、失败恢复演示、报告与视频；当前不发布最终 Release。MCP 客户端是教学用的有限 stdio 文本工具实现，不支持所有协议特性。
